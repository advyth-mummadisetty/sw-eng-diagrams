## 1. Project Overview & Introduction

### Project Identifier
- **Project-2**
- **Title:** E-Ticketing

### Problem Statement / Introduction
- **Goal:** To improve efficiency and user experience of the online train ticket booking platform.
- **Current State:** The traditional online ticketing platform has a very clumsy and non-interactive, hard to navigate user interface, and the system also faces many backend issues when many people are trying to access the platform at a time. The platform also only supports 1 form of login which is the user id and does not support other forms of login by using other platforms.
- **Proposed Solution:** The Proposed system focuses on totally overhauling the user interface of the online website and mobile application with modern understandable and easy to navigate user interface elements. It introduces seat selection, showing which seats are available clearly. It introduces new ways of login like using google id login, apple id login, facebook id login, biometric fingerprint and face id logins. The new system also introduces a loyalty program which gives extra perks and discounts during future bookings. It also strengthens the backend of the system, which decreases the amount of crashes experienced by the website and app.
- **Dynamic Updates:** The new system updates the charts (seat selection) / availability of seats every 30 seconds and updates the website and app to provide the most accurate information about seat availability.
- **Notifications:** The new system gives instant notifications to ticket holders about any changes in time of departure, platform changes, and delays through app and email notifications so that passengers do not face any trouble when they reach the station.

## 2. Existing System & Limitations

### Existing System Description
The existing system has a very non-interactive and hard to navigate online website and app. It has:
- No other platform integration logins.
- No seat selection.
- No loyalty programs.
- No change notifications.
These issues make the whole user experience unpleasant and complicated.

### Limitations of the Existing System
1. Non user interactive website and mobile app.
2. No seat selection, slow updation.
3. Only one form of login.
4. No loyalty program.
5. Crashes of website often.
6. No notifications of changes.

## 3. Proposed System Features
The Proposed system totally focuses on the following points of improvement and implementation:
- **a)** Completely overhauling the current website and mobile application with new easily understandable modern, easy to navigate user interface elements.
- **b)** Introduces seat selection, which shows how many and which seats are available clearly.
- **c)** Introduces new ways of login with other platforms.
- **d)** Introduces a loyalty system which gives users discounts and extra perks in future bookings.
- **e)** Strengthens up the backend which reduces the amount of crashes.
- **f)** Updates seat availability and seat selection every 30 seconds so that users get accurate information.
- **g)** Introduces instant notification for changes in departure/arrival time, platform changes, train rail car order changes, and delays.
- **h)** Food booking through multiple restaurants and food outlets directly delivered to your seat.
